 1. **Fork** — zrobiony na stronie GitHuba (przycisk "Fork")

 2. **Ściągnięcie SWOJEJ kopii na dysk**
`git clone <link do Twojego forka>`
`cd first-contributions`

3. **Nowa gałąź na Twoją zmianę**
`git checkout -b add-User`

 4. **Edycja pliku (w edytorze, z zapisaniem!)**
    → dopisanie siebie do Contributors.md

 5. **Zapisanie zmiany lokalnie**
`git add Contributors.md`
`git commit -m "Add User to Contributors list"`

 6. **Wysłanie NA SWÓJ fork (uwaga: origin, nie orgin!)**
`git push -u origin add-User`

 7. **Na stronie GitHuba: "Compare & pull request" → opis → Create pull request**
